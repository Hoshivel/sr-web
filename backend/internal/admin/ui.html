建立管理員帳號

後臺尚未設定。請輸入啟動日誌印出的 setup token，並設定管理員帳密。

登入

請以管理員帳密登入以管理節點與設定。

節點狀態

綠點＝探活健康、紅點＝壅塞/不可用、灰點＝已停用。建議＝後端為就近用戶選定的入點。

狀態節點URL地理延遲負載操作

新增節點

節點 id 為唯一鍵；填入既有 id 即為編輯。座標可留空改填國別碼（ISO-3166-1 alpha-2，如 HK），後端以國家質心近似就近排序。

分流設定

變更即時持久化。候選上限＝每次回傳給前端的節點數（收斂，不全敞開）。探活週期/逾時變更於下次重啟生效。
